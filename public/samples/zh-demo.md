# 从人类反馈中学习

[slide 1: 开场]
大家好，欢迎来到今天的讲座。今天我想和大家聊一聊，大语言模型是怎样从人类反馈中学习的。
// 看向观众，停顿两秒

[slide 2: 核心思想]
>> 核心：把人类偏好变成训练信号
核心思想其实很简单：我们奖励人们更喜欢的回答，惩罚人们拒绝的回答。这样一来，人类的判断就变成了一种可以优化的训练信号。

但是这里有一个问题。人类的偏好是有噪声的，不同的人经常会给出相互矛盾的判断。[[停顿]] 如果我们把这些噪声直接当成真理，模型学到的可能只是标注者的个人习惯。

[slide 3: 奖励模型]
为了解决这个问题，研究者通常会先训练一个奖励模型。奖励模型读入一个问题和一个回答，输出一个分数，表示人们有多大可能喜欢这个回答。然后，我们再用强化学习去优化语言模型，让它生成分数更高的回答。

[slide 4: 风险与总结]
不过，奖励模型本身也会犯错。当语言模型过度优化这个分数的时候，它可能会找到奖励模型的漏洞，这就是所谓的奖励黑客。所以在实践中，我们会加入一个约束，让新模型不要偏离原来的模型太远。

最后总结一下：人类反馈让模型更符合我们的期望，但它依赖于高质量的数据和谨慎的优化。谢谢大家。
