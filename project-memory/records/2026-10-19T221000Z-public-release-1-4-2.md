# Public release 1.4.2

Source: user request, 2026-10-19: push the latest version to the GitHub repository, update the version, and describe the features clearly in the README.

## Delivered
- README: a "What's new in 1.4" section (automatic `[click]` placement from the deck's builds, click to set the position with slideshow catch-up, more reliable page turns, the 1.4.1 and 1.3.1 fixes), features grouped by use, and the Keynote session-id limitation.
- Public main: commit `cb8b682`, whose tree equals the development commit `61ebde6`, on top of the 1.3.0 history (`f6c7944`). Tag `v1.4.2`.
- Release: https://github.com/MarcusYF/smart-teleprompter/releases/tag/v1.4.2 (pre-release, like 1.3.0). Assets: SmartTeleprompter-1.4.2-macOS-arm64.zip (SHA-256 3dd0fc102dab80ad3df69624c842a5881a5c7b143d6dab963743df59054af83a) and SHA256SUMS.txt. The downloaded assets match the locally tested files. 1.3.1, 1.4.0 and 1.4.1 were not released separately.

## Evidence and limits
- Before publication, the diff against public main was checked for private content (course names, paths, credentials): none.
- CI on `cb8b682`: functional (Linux) passed. Performance (Apple Silicon runner) failed on two strict timing tests ("40-60 word utterances with rewrites"). They failed the same way on `f6c7944` (1.3.0), and the tracker has not changed. This is pre-existing and not reported as a pass. The local stress suite passes 73/73.
- Live acceptance of the 1.4.2 catch-up in a real Keynote show is pending (the user is testing).

## Open
- The Keynote session-id issue (a script imported before a Keynote restart is treated as another deck) is documented, not fixed. The proposed fix identifies the deck by file path, and waits for the user's go-ahead.
- The remote timing tests need either an investigation of the runner's speed or recalibrated budgets. Not started.
